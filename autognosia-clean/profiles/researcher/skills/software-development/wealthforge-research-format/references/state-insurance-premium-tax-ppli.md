## How State Premium Taxes Work

- Excise taxes on insurance carriers based on premiums collected
- One-time charge at policy inception (not recurring)
- Locked in at domicile state — subsequent rate changes don't apply retroactively
- For PPLI: charged on the funding premium amount

## Premium Tax Impact on PPLI Economics

For a $10M policy:
- Alaska vs Nevada differential: $342,000 one-time cost
- For $50M exit: differential = $1.685M
- For $200M exit: differential = $6.74M

**Key finding:** Premium tax is typically the LEAST significant factor in PPLI domicile selection for policies above $5M. Primary drivers: carrier availability, trust law, court protection. For $1M-$5M policies, premium tax becomes a meaningful cost driver.

## Formula: Alaska Premium Tax Calculation

```
premium_tax = ($100,000 × 0.027) + ((premium - $100,000) × 0.0008)
```

For $5M policy:
```
= $2,700 + $3,920 = $6,620
effective_rate = 0.1324%
```
