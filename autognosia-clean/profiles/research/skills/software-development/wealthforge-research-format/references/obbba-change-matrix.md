# OBBBA Change Matrix — Quick Reference for Tax/Retirement Research

**One Big Beautiful Bill Act** (H.R. 1, P.L. 119-21, signed July 4, 2025)

Use this reference when any research topic touches tax, retirement, charitable, estate, or insurance planning to quickly determine whether OBBBA changed the relevant rules. The changes are sweeping — many pre-2025 financial planning norms are no longer accurate.

---

## 1. Standard Deduction & Itemization

| Provision | Pre-OBBBA (TCJA baseline) | OBBBA |
|-----------|---------------------------|-------|
| Standard deduction (single 2025) | $15,000 | $15,750 |
| Standard deduction (MFJ 2025) | $30,000 | $31,500 |
| Standard deduction (single 2026) | $12,550 (reversion) | $16,100 |
| Standard deduction (MFJ 2026) | $25,100 (reversion) | $32,200 |
| Duration | Expiring after 2025 | Made permanent + indexed |
| Itemization rate impact | ~10-14% | ~14% (SALT cap increase may bring some back) |

**Research impact:** Any tool/planning assumption using the TCJA's scheduled 2026 reversion amounts is wrong. The standard deduction stays doubled permanently.

## 2. SALT Deduction Cap

| Provision | Pre-OBBBA | OBBBA |
|-----------|-----------|-------|
| Cap amount (single/MFJ/HOH) | $10,000 | $40,000 |
| Cap amount (MFS) | $5,000 | $20,000 |
| Phaseout begins (MAGI) | N/A | $500K ($250K MFS) |
| Phaseout rate | N/A | 30% of excess over threshold |
| Indexing | N/A | Inflation-indexed from 2026 |
| 2026 specific amount | $10,000 | $40,400 |
| Sunset | After 2025 | After 2029 (reverts to $10K) |
| PTET workaround | Recognized (Notice 2020-75) | Preserved |

**Research impact:** High-SALT-state clients have a 5-year window (2025-2029) of expanded deductibility. Planning models need to handle the temporary boost and the 2030 reversion cliff. The window affects: charitable bunching decisions, mortgage paydown analysis, Roth conversion bracket space, and withdrawal sequencing.

## 3. Senior Deduction (New Provision)

| Provision | OBBBA Rule |
|-----------|-----------|
| Amount (single) | $6,000 per person, 65+ |
| Amount (MFJ) | $12,000 per couple |
| Phaseout (single) | $75,000-$175,000 MAGI |
| Phaseout (MFJ) | $150,000-$350,000 MAGI |
| Phaseout rate | ~6%/dollar (linear, 12% effective) — calculated as: max(0, (threshold - MAGI)) × 0.12 |
| Above/below line | Above-the-line deduction (available even if taking standard deduction) |
| Duration | 2025-2028 only |
| Age qualification | Must be 65+ by end of tax year |
| Interaction with QCDs | QCDs reduce MAGI, which can preserve or increase senior deduction |
| Interaction with Roth conversions | Roth conversions increase MAGI, which can reduce or eliminate senior deduction |

**Research impact:** This is a 4-year temporary deduction that massively changes Roth conversion optimization for clients 65+. The phaseout range ($150K-$350K MFJ) creates a "stealth tax" zone where each dollar of Roth conversion costs $0.06 in lost deduction. Any Roth conversion analysis for clients 65+ must model this.

## 4. Non-Itemizer Charitable Deduction (New Provision)

| Provision | OBBBA Rule |
|-----------|-----------|
| Amount (single) | $1,000 |
| Amount (MFJ) | $2,000 |
| Eligible contributions | Cash donations to 501(c)(3) public charities |
| Excluded entities | DAFs, supporting orgs, private foundations, donor-advised funds |
| Above/below line | Above-the-line reduction of AGI |
| Indexing | Fixed amounts (not inflation-indexed) |
| Effective | 2026+ (permanent) |
| Interaction with standard deduction | ADDITIONAL to standard deduction — not part of it |

**Research impact:** Changes the economics of small charitable giving for the ~86% who don't itemize. However, DAF bunching is not eligible, which affects the calculation for clients near the itemization threshold. The fixed $2K cap means only small donors benefit — anyone donating >$2K/year still needs QCDs or bunching for tax efficiency.

## 5. Charitable Deduction Floor (New Provision for Itemizers)

| Provision | OBBBA Rule |
|-----------|-----------|
| Floor amount | 0.5% of AGI |
| What it applies to | All charitable contributions (itemizers only) |
| Application order | REVERSE: 20% AGI-limit category first → 60% AGI-limit last |
| Carryforward | 5 years for amounts excluded by floor |
| Carryforward interaction | Prior-year carryovers NOT added to current-year for floor calculation |
| Effective | 2026+ |

**Research impact:** First $500 of charitable giving for $100K earner is non-deductible. For $500K earner, first $2,500 lost. The reverse application order means appreciated-property gifts to private foundations (20% category) get reduced first — a subtle trap.

## 6. 35% Cap on Charitable Benefit (For Top Bracket)

| Provision | OBBBA Rule |
|-----------|-----------|
| Applies to | Taxpayers in 37% marginal bracket |
| Cap rate | 35% (benefit capped, not deduction amount) |
| What's capped | Tax benefit of ALL itemized deductions |
| Carryforward | No carryforward for excluded amounts (this is NOT the same as the 0.5% floor) |
| Effective | 2026+ |

**Research impact:** Top-bracket clients lose $2 per $100 donated vs pre-OBBBA ($35K benefit instead of $37K on $100K gift). Combined with the 0.5% floor, the effective benefit of charitable giving for top-bracket filers shrinks from two directions simultaneously.

## 7. Roth 401(k)/403(b) RMD Elimination

| Provision | Pre-OBBBA | OBBBA |
|-----------|-----------|-------|
| Roth 401(k) RMDs | Required (started 2024 under SECURE 2.0) | Permanently eliminated |
| Roth IRA RMDs | Never required | No change (still exempt) |

**Research impact:** Strategy opportunity: bifurcate pre-tax → Traditional IRA (RMDs apply) and Roth → Roth IRA (no RMDs) effective 2024+. This affects RMD planning, conversion strategy, and QCD eligibility (QCDs only from Traditional IRAs, not Roth).

## 8. QBI Deduction (Section 199A)

| Provision | Pre-OBBBA | OBBBA |
|-----------|-----------|-------|
| QBI deduction rate | 20% | Expanded |
| SSTB phaseout | $220K-$270K (MFJ 2025) | Modified thresholds |
| Duration | Expiring after 2025 | Extended |

**Research impact:** Affects business owners, independent advisors, and any client with pass-through business income. Changes the economics of Roth conversions (QBI deduction is based on taxable income, which conversion increases).

## 9. AMT Changes

| Provision | Pre-OBBBA | OBBBA |
|-----------|-----------|-------|
| Exemption (single) | $88,100 (2025) | Increased |
| Exemption (MFJ) | $137,000 (2025) | Increased |
| Phaseout thresholds | Expanded | Further expanded |

**Research impact:** Fewer taxpayers hit by AMT reduces the sting of triggering AMT via Roth conversions or realizing gains. But the AMT still disallows SALT and state tax deductions, which matters for high-SALT clients.

## 10. Child Tax Credit

| Provision | OBBBA |
|-----------|-------|
| Amount | $2,200 per child |
| Refundable portion | $1,700 |
| SSN requirement (2026+) | Children MUST have valid SSN |

**Research impact:** Relevant for younger client planning (families with children, education planning).

## Research Flowchart

When beginning ANY tax/retirement/charitable research:

```
1. Cross-reference the topic against this matrix
   ↓
2. If topic IS listed above:
   → Use OBBBA rules as the basis for research
   → Cite OBBBA sources (Kitces July 2025, Tax Foundation, IRS)
   → Note the sunset/effective dates where applicable
   ↓
3. If topic is NOT listed above:
   → Pre-2025 sources may still be valid
   → But check if OBBBA changed a related provision that indirectly affects it
   → (e.g., OBBBA didn't change SS directly, but changed tax brackets and standard deduction that SS taxation interacts with)
   ↓
4. If topic is a "permanent" rule changed by OBBBA:
   → The new rule is the current law baseline
   → Historical analysis is fine for context; current planning uses new rules
   ↓
5. If topic has a sunset date (e.g., senior deduction 2028, SALT cap 2029):
   → Model BOTH current benefit AND the post-sunset state
   → The temporary nature IS the planning opportunity
```
