# OBBBA State Decoupling Tracker (Run 244 Addendum)

**As of May 2026, 17+ states have decoupled from various OBBBA provisions.** This creates state MAGI ≠ federal MAGI for many clients, directly impacting Roth conversion planning, withdrawal optimization, and state tax calculations.

## Decoupling States (Run 244 Verified)

| State | Conformity Type | OBBBA Provisions Decoupled From | Impact Level |
|-------|----------------|--------------------------------|-------------|
| **California** | Static (IRC conformity date) | ALL OBBBA provisions — specifically ensured IRC conformity date does NOT incorporate OBBBA | HIGH — affects Senior Bonus Deduction ($6K/$12K), SALT cap ($40K), all base changes |
| **Michigan** | Rolling → Decoupled (HB 4961, Oct 2025) | IRC §174 (R&E), bonus depreciation (§168(k)), QPP deduction (§168(n)), business interest limitation (§163(j)) | MEDIUM — corporate provisions; retirement income provisions may still conform |
| **Virginia** | Static | ALL OBBBA provisions — paused automatic adoption | HIGH — affects all federal changes |
| **Rhode Island** | Static → Decoupled (ADV 2025-18) | IRC §174 (R&E deduction) | LOW — corporate only |
| **Maryland** | Static (>$5M revenue impact threshold) | ALL OBBBA provisions (revenue impact >$5M triggers automatic decoupling) | HIGH — affects all provisions |
| **Colorado** | Rolling | Automatic conformer (budget shortfall caused by automatic OBBBA adoption) | NONE — conforms automatically |
| **Pennsylvania** | Rolling → Decoupled (Act 45 of 2025) | Corporate net income tax (CNIT) from certain federal business breaks | MEDIUM — corporate only |

## States Fully Conforming to OBBBA (Rolling Conformity)
- **Colorado** — automatic conformer (caused budget shortfall)
- **~18 states** with rolling IRC conformity fully adopt OBBBA
- **~12 states** fully decouple from bonus depreciation (§168(k))
- **~20 states** have partial decoupling, electable conformity, or no income tax

## Research Impact

**When researching ANY tax topic post-OBBBA:**
1. **Check the client's domicile state** against this decoupling table
2. **If the state decoupled:** the client does NOT get that federal provision for state tax purposes
3. **State MAGI may differ from federal MAGI** — Roth conversion calculations must use state-specific MAGI
4. **Senior Bonus Deduction ($6K/$12K):** Only available at state level if the state conforms. CA, MD, VA clients do NOT get it for state tax.
5. **SALT cap ($40K):** Only available at state level if the state conforms. Decoupled states still use $10K cap.
