## Qualified vs Non-Qualified Expenses

**Qualified (Higher Ed):** Tuition, fees, room/board (half-time enrollment+), books, supplies, equipment, computer/internet, special needs services, credential programs (WIOA, WEAMS, DOL-registered apprenticeships)

**Qualified (K-12, OBBBA 2026):** Up to $20K/yr — tuition, curriculum materials, textbooks, workbooks, digital learning tools, online materials, tutoring (licensed teacher/subject expert), standardized test fees (SAT/ACT/AP), dual-enrollment fees, educational therapies (occupational/behavioral/physical/speech-language for students with disabilities)

**Qualified (Career):** Professional licenses (CPA, Bar), certifications, trade credentials, continuing education, vocational programs (welding, plumbing, cosmetology, CDL, HVAC, EMT)

**Non-Qualified:** Transportation, health insurance, sports/activity fees (unless required), application fees, loan application fees

**Penalty:** Non-qualified withdrawals trigger federal income tax on earnings + 10% penalty (exceptions: scholarship, death, disability, US military academy attendance)

## SECURE 2.0 — 529-to-Roth IRA Rollover (Effective 2024+)

| Rule | Detail |
|------|--------|
| Lifetime limit | $35,000 per beneficiary |
| Annual cap | Roth IRA contribution limit for that year ($7,500 in 2026) |
| Account age | Must be open 15+ years at rollover date |
| Contribution age | Contributions from last 5 years (and their earnings) ineligible |
| Beneficiary | Must own BOTH the 529 and the Roth IRA |
| Earned income | Beneficiary must have earned income >= rollover amount |
| Transfer type | Direct trustee-to-trustee only (not a distribution + deposit) |
| Income limits | NONE — high earners can use this to bypass Roth income phaseouts |

**Strategy:** Open 529 at birth with minimal deposit ($25-50) to start the 15-year clock. Rollovers can begin at age 15. Timeline: age 15 ($7,500) → 16 ($7,500) → 17 ($7,500) → 18 ($7,500) → 19 ($5,000) = $35,000 lifetime max by age 19.

**Key warning:** Children who earn nothing cannot do the rollover. The earned income requirement is the binding constraint for most college students. Summer jobs, internships, and part-time work are the path to eligibility.

## FAFSA/SAI Impact Rules

| Ownership Type | FAFSA/SAI Assessment | Note |
|----------------|---------------------|------|
| Parent-owned | 5.64% of account value | Recommended structure for most families |
| Student-owned (UGMA/UTMA) | 20% of account value | AVOID — costly mistake |
| Grandparent-owned | 0% (not counted as asset) | FAVORABLE under FAFSA Simplification Act |

**CSS Profile (College Board, ~250 selective schools):**
- May count ALL parent 529 accounts (not just beneficiary's)
- May count grandparent 529s as assets
- Higher assessment rates (varies by school, up to 25%)
- School-specific formula — cannot fully generalize
- IF client's target schools require CSS Profile, grandparent 529 strategy differs

**Key metric:** Each $10K in parent-owned 529 adds ~$564 to the Student Aid Index. Real-world aid impact: typically reduces need-based aid by $282-$564/year (roughly half the SAI increase for a 9-month academic year).

**Income vs assets:** Parental income is assessed at 25-47% — far more impactful than 529 assets at 5.64%. For high-income families, 529 aid impact is often negligible.

## OBBBA Changes (Signed July 4, 2025, Effective 2026)

| Change | Details |
|--------|---------|
| K-12 limit doubled | $10,000 → $20,000/year per student |
| Expanded K-12 expenses | Books, tutoring, educational therapies, test fees, homeschooling materials, digital tools |
| Credentialing | Trade certifications, vocational licenses, WIOA-approved programs now qualified |
| ABLE rollovers | 529→ABLE rollovers made permanent (previously set to expire) |

## 50-State Deduction Categories (High-Level)

| Category | States | Example Limits |
|----------|--------|----------------|
| Unlimited deduction | CO, ME, NM, SC, WV | 100% of contributions (some restricted to in-state plan) |
| Per-beneficiary deduction | NY, PA, OH, KS, AZ | $10K-$19K per child. PA: $19K/beneficiary |
| Fixed deduction (not per beneficiary) | IL, IN, IA, VA, etc. | $5K-$10K per return |
| No deduction | CA, DE, HI, KY, MA, etc. | $0 — no state tax benefit |
| Tax parity (any state's plan) | AZ, KS, ME, MN, MO, MS, PA | Deduction regardless of which state sponsors the plan |

**Full parity states:** Arizona, Kansas, Maine, Minnesota, Missouri, Mississippi, Pennsylvania (deduction any plan). Some have per-beneficiary limits making them generous for large families.

**K-12 state conformity warning:** ~10 states (CA, HI, IL, MN, MT, NY, VT, potentially OR, NJ, VA) do not conform to federal K-12 expansion. Taking a state deduction on contributions → withdrawing for K-12 tuition → may trigger state-level recapture of the deduction.

## Superfunding Mechanics

- Can contribute up to 5× annual gift exclusion ($95K single, $190K married) per beneficiary in one year
- Must file IRS Form 709 to elect the 5-year spread
- Contribution counts as gift spread over 5 years for gift tax purposes
- **Estate inclusion risk:** If contributor dies within the 5-year period, unallocated years return to contributor's taxable estate
- Beneficiary changes during the 5-year period may be treated as a new gift

## Ownership Strategy Decision Tree

```
Client has children? → NO → No 529 needed
                    → YES → Who will own?

Parent-owned:     Best for FAFSA (5.64%), max control, max flexibility
                  Use for: most families, especially if need-based aid expected

Student-owned:    WORST for FAFSA (20% assessment)
                  Use for: never (change ownership if existing)

Grandparent-owned: FAFSA-exempt (0% asset), CSS may count
                  Use for: high-NW families, schools don't require CSS Profile
                  Trap: CSS Profile schools may count as student resource
```

## Documentation Retention Requirements

- Federal minimum: 3 years from filing date
- Expert recommendation: Keep records until last dollar leaves the account
- Must prove: original contributions (for state deduction recapture defense) AND qualified nature of each withdrawal (to avoid federal penalties)
- Do NOT use Form 1099-Q for claiming state deductions (it's for distributions only)
