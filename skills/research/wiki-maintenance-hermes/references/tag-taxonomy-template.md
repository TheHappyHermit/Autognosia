# Tag Taxonomy Template — AI/ML Research Domain

Copy this into `SCHEMA.md` and adapt to your domain. **Rule: every tag on a page must appear in this taxonomy. Add new tags HERE first, then use them.**

---

## Core Domain Tags (always available)

- `llm` — large language models generally
- `architecture` — model architectures (transformer, MoE, SSM, etc.)
- `training` — pre-training, fine-tuning, RLHF, DPO, GRPO
- `inference` — serving, quantization, KV caching, speculative decoding
- `evaluation` — benchmarks, eval frameworks, human eval
- `prompting` — prompt engineering, CoT, few-shot, system prompts
- `rag` — retrieval-augmented generation, embeddings, vector DBs
- `agents` — autonomous agents, tool use, planning, delegation
- `multi-agent` — agent swarms, orchestration, communication
- `alignment` — safety, RLHF, constitutional AI, interpretability
- `efficiency` — quantization, distillation, pruning, MoE
- `hardware` — GPU/TPU, inference accelerators, memory hierarchy

## Entity Tags (for entity pages)

- `model` — specific models (gpt-4, llama-3, nemotron, etc.)
- `company` — organizations (OpenAI, Anthropic, Google, Nous, etc.)
- `person` — researchers, engineers, thought leaders
- `paper` — seminal papers (attention-is-all-you-need, etc.)
- `framework` — libraries (LangChain, AutoGen, CrewAI, LlamaIndex, Hermes, etc.)
- `dataset` — training/eval datasets
- `benchmark` — MMLU, GSM8K, HumanEval, etc.
- `agent` — autonomous agent frameworks/systems (Hermes, etc.)
- `multi-platform` — runs on multiple messaging/social platforms
- `skills` — skill system, self-improving procedures
- `memory` — persistent cross-session memory
- `delegation` — subagent spawning, orchestration

## Concept Tags (for concept pages)

- `theory` — theoretical foundations
- `technique` — practical methods/tricks
- `pattern` — recurring design patterns
- `tradeoff` — explicit tradeoff analyses
- `pitfall` — common mistakes/warnings

## Meta Tags

- `meta` — wiki-level pages (SCHEMA, index, log, HOW-TO-USE)
- `seed` — example/template pages
- `deprecated` — superseded content (moved to `_archive/`)
