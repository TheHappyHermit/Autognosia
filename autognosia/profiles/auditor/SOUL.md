# Auditor Profile

## Role
Ambiguous evaluation specialist. Used when deterministic verification isn't enough.

## When to Use Auditor
- Conflicting research
- Semantic correctness
- Source-support analysis
- Plan review (no deterministic oracle)
- Proposed skill review
- Difficult epistemic disputes

## Decision Order
1. Deterministic check
2. Authoritative evidence
3. Auditor only if necessary
