## 1. Geospatial and Mapping APIs

### 1.1 OpenStreetMap (Nominatim)
- **URL**: `https://nominatim.openstreetmap.org/`
- **Description**: Geocoding and reverse geocoding service based on OpenStreetMap data.
- **Rate Limits**: 1 request per second.
- **Use Cases**:
  - Convert addresses to coordinates (geocoding).
  - Convert coordinates to addresses (reverse geocoding).
  - Map OSINT findings to physical locations.

**Example Request**:
```bash
curl "https://nominatim.openstreetmap.org/search?format=json&q=Seattle"
```

### 1.2 Overpass API
- **URL**: `https://overpass-api.de/api/`
- **Description**: Query OpenStreetMap data directly using a custom query language.
- **Rate Limits**: Public instances have usage limits; consider running your own instance.
- **Use Cases**:
  - Extract specific OSM data (e.g., all Wi-Fi hotspots in Seattle).
  - Find points of interest (e.g., radio towers, emergency services).

**Example Request**:
```bash
curl "https://overpass-api.de/api/interpreter?data=[out:json];node['amenity'='restaurant'](47.6,-122.3,47.7,-122.2);out;"
```

### 1.3 USGS Earthquake API
- **URL**: `https://earthquake.usgs.gov/fdsnws/event/1/`
- **Description**: Real-time and historical earthquake data.
- **Rate Limits**: None for basic queries.
- **Use Cases**:
  - Monitor seismic activity in the Pacific Northwest.
  - Correlate earthquakes with emergency radio traffic.

**Example Request**:
```bash
curl "https://earthquake.usgs.gov/fdsnws/event/1/query?format=geojson&latitude=47.6&longitude=-122.3&maxradiuskm=200"
```

### 1.4 NASA Earthdata
- **URL**: `https://earthdata.nasa.gov/`
- **Description**: Access to NASA's satellite imagery and environmental data.
- **Rate Limits**: Free registration required for some datasets.
- **Use Cases**:
  - Satellite imagery for environmental OSINT.
  - Weather and climate data analysis.

**Example Request**:
```bash
# Requires registration and API key
curl -H "Authorization: Bearer YOUR_API_KEY" "https://api.nasa.gov/planetary/earth/imagery?lon=-122.3&lat=47.6&date=2023-01-01&api_key=YOUR_API_KEY"
```

## 2. Maritime and Aviation APIs

### 2.1 MarineTraffic
- **URL**: `https://www.marinetraffic.com/en/p/partner/api`
- **Description**: AIS vessel tracking data.
- **Rate Limits**: Free tier available with limited requests.
- **Use Cases**:
  - Track vessels in Puget Sound.
  - Correlate AIS data with SDR captures.

**Example Request**:
```bash
curl "https://services.marinetraffic.com/api/exportvessels/v:7/timespan:2/area:47.6,-122.3,47.7,-122.2/x:YOUR_API_KEY/protocol:json"
```

### 2.2 OpenSky Network
- **URL**: `https://opensky-network.org/api/`
- **Description**: Real-time and historical ADS-B aircraft tracking data.
- **Rate Limits**: Free for non-commercial use.
- **Use Cases**:
  - Track aircraft over Seattle-Tacoma Airport (KSEA).
  - Analyze flight patterns and anomalies.

**Example Request**:
```bash
curl "https://opensky-network.org/api/flights/all?begin=1517227200&end=1517230800"
```

### 2.3 FlightAware
- **URL**: `https://www.flightaware.com/commercial/flightxml/`
- **Description**: Flight tracking and aviation data.
- **Rate Limits**: Free tier available with limited requests.
- **Use Cases**:
  - Track commercial and private flights.
  - Correlate with ADS-B data from SDR captures.

**Example Request**:
```bash
curl "https://flightxml.flightaware.com/json/FlightXML3/InFlightInfo?ident=UAL123&howMany=15&offset=0" -H "Authorization: Basic YOUR_API_KEY"
```

## 4. Radio and Satellite APIs

### 4.1 Celestrak
- **URL**: `https://celestrak.org/NORAD/elements/`
- **Description**: Satellite Two-Line Element (TLE) data.
- **Rate Limits**: None.
- **Use Cases**:
  - Track satellites visible from Seattle.
  - Predict satellite passes for SDR captures.

**Example Request**:
```bash
curl "https://celestrak.org/NORAD/elements/gp.php?GROUP=active&FORMAT=tle"
```

### 4.2 N2YO
- **URL**: `https://www.n2yo.com/api/`
- **Description**: Real-time satellite tracking.
- **Rate Limits**: Free tier available with limited requests.
- **Use Cases**:
  - Visualize satellite positions in real-time.
  - Correlate with SDR satellite signal captures.

**Example Request**:
```bash
curl "https://www.n2yo.com/rest/v1/satellite/positions/25544/47.6/-122.3/0/2/&apiKey=YOUR_API_KEY"
```

### 4.3 SatNOGS
- **URL**: `https://db.satnogs.org/api/`
- **Description**: Open-source satellite ground station network data.
- **Rate Limits**: None for public data.
- **Use Cases**:
  - Access satellite telemetry and observations.
  - Correlate with local SDR captures.

**Example Request**:
```bash
curl "https://db.satnogs.org/api/transmitters/?format=json"
```

### 6.2 Reddit API
- **URL**: `https://www.reddit.com/dev/api/`
- **Description**: Access to Reddit posts and comments.
- **Rate Limits**: Free with rate limits.
- **Use Cases**:
  - Monitor discussions and trends.
  - Gather OSINT from public forums.

**Example Request**:

- **URL**: `https://archive.org/help/json.php`

## 9. Usage Examples

### 9.1 Correlating AIS and ADS-B Data
```python
import requests
import pandas as pd

# Fetch AIS data from MarineTraffic
ais_url = "https://services.marinetraffic.com/api/exportvessels/v:7/timespan:2/area:47.6,-122.3,47.7,-122.2/x:YOUR_MARINETRAFFIC_API_KEY/protocol:json"
ais_response = requests.get(ais_url)
ais_data = ais_response.json()

# Fetch ADS-B data from OpenSky
adsb_url = "https://opensky-network.org/api/flights/all?begin=1517227200&end=1517230800"
adsb_response = requests.get(adsb_url)
adsb_data = adsb_response.json()

# Convert to DataFrames
ais_df = pd.DataFrame(ais_data)
adsb_df = pd.DataFrame(adsb_data['states'])

# Correlate by timestamp and location
merged = pd.merge_asof(
    ais_df.sort_values('TIMESTAMP'),
    adsb_df.sort_values('time'),
    left_on='TIMESTAMP',
    right_on='time',
    tolerance=pd.Timedelta('1s'),
    direction='nearest'
)

# Save to CSV
merged.to_csv('correlated_ais_adsb.csv', index=False)
print("Correlated AIS and ADS-B data saved to correlated_ais_adsb.csv")
```

### 9.2 Geocoding Addresses with OpenStreetMap
```python
import requests

def geocode_address(address):
    url = f"https://nominatim.openstreetmap.org/search?format=json&q={address}"
    response = requests.get(url).json()
    if response:
        return {
            'lat': response[0]['lat'],
            'lon': response[0]['lon'],
            'display_name': response[0]['display_name']
        }
    return None

# Example usage
location = geocode_address("Space Needle, Seattle")
print(f"Space Needle coordinates: {location['lat']}, {location['lon']}")
```

### 9.3 Tracking Satellites with Celestrak
```python
import requests

def get_satellite_tle(satellite_id):
    url = f"https://celestrak.org/NORAD/elements/gp.php?CATNR={satellite_id}&FORMAT=tle"
    response = requests.get(url).text
    return response.splitlines()

# Example: ISS (ID 25544)
tle_lines = get_satellite_tle(25544)
print("TLE for ISS:")
for line in tle_lines:
    print(line)
```

## 11. Legal and Ethical Considerations

### 11.1 Legal Compliance
- **Data Privacy**: Ensure compliance with **GDPR**, **CCPA**, and other privacy laws when handling personal data.
- **API Terms**: Always review and comply with the **terms of service** for each API.
- **Rate Limits**: Respect API rate limits to avoid being blocked.

### 11.2 Ethical Guidelines
- **Transparency**: Be transparent about data collection and usage.
- **Consent**: Obtain consent when collecting data on individuals.
- **Minimization**: Collect only the data necessary for your analysis.
- **Anonymization**: Anonymize personal data in reports and logs.
